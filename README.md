# User Management API (ASP.NET Core)

A simple User Management REST API built using **ASP.NET Core Web API**.  
This project was created as part of an assignment to demonstrate:

- CRUD operations  
- Data validation  
- Middleware implementation  
- Debugging with GitHub Copilot  
- Publishing code to a GitHub repository  

---

## 🚀 Features

### ✔ CRUD Endpoints
The API supports:
- **GET** all users  
- **GET** user by ID  
- **POST** create user  
- **PUT** update user  
- **DELETE** remove user  

### ✔ Validation
The User model includes:
- Required fields  
- Email validation  
- String length validation  
- Age range validation  

### ✔ Custom Middleware
A simple **logging middleware** is added to log incoming requests and responses.

### ✔ Debugging with Copilot
GitHub Copilot suggestions were used to:
- Fix errors  
- Improve code readability  
- Generate middleware  
- Complete controller
